Как PDF превращается
в ответ со ссылками

DocChat ищет ответ в выбранном PDF с помощью E5 и BM25, затем передаёт найденные фрагменты локальной модели. Выберите узел, чтобы посмотреть его входы, результат и реализацию.

Что и где хранится

Файлы на диске

data/uploads/{id}.pdf
Исходный PDF. SHA-256 помогает распознать повторную загрузку.

SQLite

data/docchat.db
Документы, статусы, текст чанков, страницы и сообщения. Источник текста для восстановления BM25.

Chroma + память процесса

data/chroma/: векторы, отдельная коллекция на документ.
BM25 и блокировки чата находятся в памяти одного процесса.

Решения и их ограничения

РешениеЗачемОграничение
FastAPI + обычный JavaScriptREST, загрузка файлов и поток ответа без отдельной frontend-сборки.Нет авторизации и разделения пользователей. Приложение рассчитано на локальную работу.
Чанки по страницамФрагмент сохраняет физический номер страницы для ссылки.Страница не равна смысловому разделу. Короткие хвосты могут объединяться со следующей страницей.
E5 + BM25E5 ищет по смыслу; BM25 находит точные коды, названия и термины.Нужны два поиска. Небольшой синтетический набор не доказывает преимущество на любых документах.
Reciprocal Rank FusionСкладываются обратные ранги, поэтому шкалы cosine и BM25 не требуется приводить к общему масштабу.RRF использует порядок, но теряет величину разницы между соседними оценками.
Gate до LLMОтсекает часть явно посторонних вопросов и экономит генерацию.Сходство не доказывает наличие ответа. Gate может отклонить ответимый вопрос или пропустить вопрос без ответа.
История только для уточнения«А до установки?» превращается в самостоятельный вопрос. Ответ строится заново по документу.Ошибочное уточнение остаётся возможным; предыдущий ответ может повлиять на разрешение отсылок.
Одна локальная модель 3B Q4Ministral проверена на MacBook Air M1 с 8 ГБ RAM. Контекст сервера: 8192 токена, запросы выполняются последовательно.Маленькая модель может пропускать условия, ошибаться в расчётах и ссылках. Температура 0 не гарантирует одинаковые ответы.
Реранкер выключен по умолчаниюМеньше памяти и затрат CPU. Его можно включить отдельным параметром.Cross-encoder загружает ещё одну модель и увеличивает время поиска. Результаты базовой конфигурации к нему не относятся.
Один процесс UvicornПростая локальная сборка; индексация последовательна, по документу разрешён один активный ответ.Блокировки и фоновые задачи не распределены между процессами. Несколько workers этой конфигурацией не поддерживаются.
